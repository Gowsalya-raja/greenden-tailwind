# 🌿 Greenden Website

Greenden is a responsive plant and gardening website created using **HTML and Tailwind CSS**. The project focuses on building a clean, modern, and user-friendly website layout while practicing responsive web design and Tailwind CSS utilities.

## 🚀 Technologies Used

* HTML5
* Tailwind CSS

## ✨ Features

* Responsive navigation bar
* Modern and clean UI design
* Plant product sections
* Responsive layout for different screen sizes
* Styled using Tailwind CSS utility classes
* Simple and beginner-friendly project structure

## 📱 Responsive Design

The website is designed to work across:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet

## 🎯 Purpose

This project was created as a **frontend practice project** to improve my skills in:

* HTML structure
* Tailwind CSS
* Responsive web design
* Flexbox and Grid
* UI layout and styling
